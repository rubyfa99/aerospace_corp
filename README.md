# dynamic-space-ops
This is the repository for the Dynamic Space Ops GC.

This repository is broken into two branches:  `main` and `development`.

# main
Code in `main` is guaranteed to be stable.  Merging into `main` requires approval from the entire team.

# development
Actual code development shouldn't take place in the `development` branch.  Instead, create a branch off of `development` and merge that branch into `development` when the code update is complete.  Once it's verified that the new `development` is stable, it can be merged into `main`.
